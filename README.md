# ExTrInOut

**ExTrInOut (Extrinout)** is a simple yet versatile expense tracker built around one core idea: **accounts first, categories second**. Instead of blending all expenses into a single pool, ExTrInOut allows users to separate spending by context, making financial tracking clearer, more flexible, and more practical.

---

## Overview

ExTrInOut was originally developed to manage both:

* Personal daily expenses
* Organizational and event-based costs (such as Model United Nations and other hosted events)

This dual-purpose origin shaped the system’s design, ensuring it works equally well for individual use and structured, project-based financial tracking.

---

## Key Concept: Accounts

What sets ExTrInOut apart is its emphasis on **accounts** rather than relying solely on categories.

With accounts, users can:

* Separate daily personal spending from event or project budgets
* Track multiple events or projects independently
* Monitor expenses across different people or purposes (e.g. parental oversight)

Each account functions as its own financial context, preventing unrelated expenses from being mixed together while still allowing detailed categorization within each account.

---

## Why ExTrInOut?

* **Clear separation of finances** – no single blended expense pool
* **Flexible use cases** – personal, organizational, or professional
* **Simple structure** – easy to understand and extend
* **Scalable design** – suitable for both small daily tracking and larger projects

This approach makes ExTrInOut more adaptable and inclusive than conventional expense trackers.

---

## Running the Application

ExTrInOut is built using **Flask**.

To start the application, run the following command from the project root:

```bash
python -m flask run
```

Make sure your virtual environment is activated and dependencies are installed before running the command.

---

## Conclusion

ExTrInOut goes beyond traditional expense trackers by prioritizing financial context through accounts. This design choice keeps finances organized, transparent, and adaptable to a wide range of real-world use cases; without unnecessary complexity.
